# THE ABYSS
The abyss is a mod developed for deep water exploration when paired with other mods like [Create: Deep Seas](https://modrinth.com/mod/create-deep-seas), allowing the player to go a thousand blocks underwater, alone with nothing but their imagination. The mod is fairly simple, only containing a dimension, biome, and some other small things like custom commands and structures.
